How this map stays traversable and updatable

The canonical graph is docs/simpleagent-map/graph.json in SimpleAgentOS. Nodes have stable IDs; directed edges describe relationships. The HTML contains the same graph in script#graph-data and works offline.

Use python3 docs/simpleagent-map/map.py show journal to inspect evidence and connections, or walk journal --depth 2 to traverse. After editing the JSON, run validate, check-sources, and build. File hashes flag source drift; they do not prove a finding is still true.

Direct links store view and node in the URL fragment. Browser Back and Forward retrace your route. Use Tab and Enter to select nodes, or the text index below the diagram. On narrow screens, the diagram scrolls horizontally.
